# 微证券界面与牛来选股演示

这是独立制作的静态前端学习演示，与腾讯及腾讯微证券没有关联，不是腾讯官方服务。

- 网站：https://hitliujiahao.github.io/
- 牛来选股页：https://hitliujiahao.github.io/niulai.html?v=3
- 首页点击“立即进入”可打开牛来，支持返回首页。

## 股票搜索

目录共 14,116 个证券标识：A 股 5,565、港股 2,823、美股 5,728。沪深北与香港目录获取日期为 2026-09-18；美国官方目录生成日期为 2026-09-17。不同交易市场、股类与柜台分别计数，不是上市公司数量。

支持名称、完整代码、拼音首字母、全拼、港股繁简名称、英文名称；常用美股保留中文别名。支持 SH600519、600519.SH、700、00700.HK、BRK.B 等输入。同名跨市场及多股类股票需要点选确认，不会静默代选。

覆盖沪深北 A 股、港交所股本证券与 REIT、美股交易所普通股/ADR/REIT 等权益证券。不是全球所有市场；不含 OTC、ETF、优先股、债券、权证、退市证券。目录是本地快照，新上市、更名、退市需刷新，不保证实时或绝对完整。北交所 5 个未能通过交易代码核验的候选没有混入目录，详见 `stock-directory-meta.json`。

目录加载失败时会提示具体市场并提供重试，仅临时使用常用股票。所有名单随站点托管，不要求访问者连接境外数据接口。

## 图表建议

牛来建议以量价走势、行业观察雷达、新闻情绪环图与关注热度、技术指标信号为主。支持 20/60 日切换、滑块查看指定模拟交易日、MACD/RSI/成交量切换和新闻情绪分类选择。

**图表和观点全部为明确标注的模拟内容。所有股票共用同一组模拟样本，不代表所选股票真实行情或新闻，也不构成投资建议。** 没有接入实时资讯、行情或大模型服务。MACD 和 MA20 由同一模拟价格序列计算；RSI14 采用最近 14 日涨跌幅简单平均口径；成交量比为末日模拟量除以前 5 日均量，均在页面注明。

前端不收集账号、密码等个人信息；GitHub Pages 平台可能按其隐私声明处理访问日志。

## 数据来源与更新

- [上海证券交易所](https://www.sse.com.cn/assortment/stock/list/share/)：主板 A 股及科创板。
- [深圳证券交易所](https://www.szse.cn/market/stock/company/)：A 股股票列表。
- [巨潮资讯](https://www.cninfo.com.cn/)：北交所代码，辅以[腾讯行情](https://gu.qq.com/)公开证券代码记录核验，排除已退市与尚未验证的代码。
- [香港交易所](https://www.hkex.com.hk/Services/Trading/Securities/Securities-Lists?sc_lang=zh-HK)：中英文证券名单，筛选股本证券与 REIT。
- [Nasdaq Trader](https://www.nasdaqtrader.com/Trader.aspx?id=SymbolDirDefs)：Nasdaq 及其他美国交易所证券名单，排除 ETF、测试证券、权证、债券、优先股及其他非普通权益证券。

刷新工具位于 `scripts/refresh_stock_directory.py`，依赖列在 `scripts/requirements.txt`。使用 Python 3 安装这些依赖后执行该脚本即可生成三个市场的目录分片及元数据；数据获取不完整时拒绝覆盖现有目录。核对变更后再提交发布。未设置自动刷新任务。

使用原生 HTML、CSS、JavaScript 与 SVG，无需构建。GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 用于直接提供静态文件。

腾讯相关名称、标识及参考形象属于其各自权利人，仅用于本演示的界面学习与展示。
