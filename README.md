# 微证券界面与牛来选股演示

这是独立制作的静态前端学习演示，与腾讯及腾讯微证券没有关联，不是腾讯官方服务。

- 网站：https://hitliujiahao.github.io/
- 牛来选股页：https://hitliujiahao.github.io/niulai.html?v=2
- 首页点击“立即进入”可打开牛来，支持返回首页。

## 牛来功能

- 98 只 A 股（沪深北）、港股和美股的本地演示股票库，并非全市场实时目录。
- 支持名称、代码、拼音首字母、拼音全拼和英文别名联想；可点选候选或输入明确名称、代码后直接提问。
- 同名跨市场股票会要求确认。支持市场筛选、键盘选择、中文输入、清空和无结果反馈。
- 建议分为行业资讯、热点新闻、技术指标异动三个部分，全部为明确标注的条件式示例。

当前没有接入实时资讯、行情或大模型，不提供真实开户、交易或个股买卖建议。前端不收集账号、密码等个人信息；GitHub Pages 平台可能按其隐私声明处理访问日志。

使用原生 HTML、CSS 和 JavaScript，无需构建。GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 用于直接提供静态文件。

腾讯相关名称、标识及参考形象属于其各自权利人，仅用于本演示的界面学习与展示。北交所样例代码参考[官方代码对照表](https://www.bse.cn/service/code_mapping.html)。
